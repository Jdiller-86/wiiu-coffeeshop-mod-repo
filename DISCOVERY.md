# More Wii U mods to explore

Researched **2026-10-03**. These are notable projects with original creator or project pages. They are **not entries in this repository's live Coffee Shop feed**. Coffee Shop needs a direct HTTPS ZIP that extracts to an SDCafiine-ready `content/` and/or `aoc/` directory at the archive root. Some projects require a separate mod manager, game dump, region-specific build, or an archive format Coffee Shop cannot install. For others, the published ZIP's root layout has not been verified. Follow each project's own instructions before trying it on a Wii U.

| Game | Mod and original page | Why it is a manual discovery link |
| --- | --- | --- |
| Breath of the Wild | [Second Wind](https://github.com/CEObrainz/Second-Wind/blob/main/WiiU.md) | The team's Wii U guide requires a v1.5.0 game dump with DLC, then UKMM merges and deploys the mod. Its UKMM input ZIP is not a ready-to-extract Coffee Shop pack. |
| Breath of the Wild | [Relics of the Past](https://gamebanana.com/mods/414822) | This large gameplay overhaul needs compatibility-aware mod merging. The project's [older download page](https://gamebanana.com/mods/149523) offers a `.7z` archive, which Coffee Shop cannot extract. |
| Breath of the Wild | [The Linkle Mod 3.0](https://gamebanana.com/mods/406768) | The base character overhaul is used with BCML or UKMM and has optional add-ons and compatibility patches. A direct, standalone root-`content/` ZIP has not been verified. |
| Super Smash Bros. for Wii U | [Melee HD](https://videogamemods.com/mastaklo-mods/super-smash-bros/mods/melee-hd) | The creator supplies packed, unpacked, and PAL variants through MEGA. Select the correct region and build a suitable SDCafiine pack manually. |
| Super Smash Bros. for Wii U | [Training Modpack](https://gamebanana.com/mods/48370) | Its download bundles multiple game-region/packed variants. The complete archive is not one installable mod folder. |
| Super Mario Maker | [New Super Mario Bros. Wii Theme](https://gamebanana.com/mods/421748) | A Wii U mod page exists, but the direct ZIP target and root layout have not been verified for Coffee Shop. |
| Super Mario Maker | [The Metroid Mod](https://gamebanana.com/mods/50015) | The main file is `.rar`, and its region requirements still need review before any Coffee Shop package could be considered. |
| Super Mario Maker | [Super Luigi Maker](https://gamebanana.com/mods/248093) | Its ZIP was checked and has two `Super Luigi Maker/` wrapper folders above the game files, so Coffee Shop cannot install it directly. |
| Minecraft: Wii U Edition | [My Skin Pack](https://gamebanana.com/mods/534259) | The author's installation steps use FTPiiU to replace a DLC `.pck` file in the console's title storage. Coffee Shop's SDCafiine extraction does not perform that replacement. |
| Minecraft: Wii U Edition | [Minecraft Texture Overhaul](https://gamebanana.com/mods/432893) | Its three Wii U region ZIPs were published for SDCafiine, but the USA archive was checked and starts with `USA/<Title ID>/Texture Overhaul/content/`; Coffee Shop needs `content/` at the root. |
| Minecraft: Wii U Edition | [Trainer 16x LCE Edition](https://gamebanana.com/mods/549060) | The author directs users to instructions inside the ZIP for replacing textures and files. An SDCafiine-ready root layout has not been verified. |
| Pikmin 3 | [Extra Side of Stories](https://www.youtube.com/watch?v=EN_gJ0k7CnM) | The creator's release trailer links a separate Wii U build in its description. The Wii U download's stable direct ZIP URL and root layout have not been verified; the hardware version also has fewer usable stages than the full set. |
| Pikmin 3 | [Bulbmin Forever](https://www.youtube.com/watch?v=S_7-3igc-xw) | The creator links the current hack from the video description. The actual archive URL and structure have not been verified for direct Coffee Shop installation. |
| Super Mario 3D World | [Waluigi outfit for Luigi](https://gamebanana.com/mods/247910) | The download is `.7z`; the author also warns SDCafiine can crash when loading a new level and recommends other methods for console use. |
| Super Mario 3D World | [Super Refreshed 3D World: Complete World 1 Overhaul](https://gamebanana.com/mods/631460) | The author rebuilt World 1. Its ZIP was checked and starts with `super_refreshed_3d_world/content/`, one folder too deep for Coffee Shop. |
| Mario Kart 8 | [Wii Rainbow Road V2](https://gamebanana.com/mods/430852) | The creator identifies it as Wii U/Cemu-only and replaces Grumble Volcano. Its ZIP was checked and starts with `Wii Rainbow Road (REDO)/content/`, one folder too deep for Coffee Shop. |
| Mario Kart 8 | [N64 Rainbow Road City exploration](https://gamebanana.com/mods/448648) | The Wii U port is published as a `.7z` main mod, which Coffee Shop cannot extract. |
| New Super Mario Bros. U / New Super Luigi U | [Luigi's Lost Levels](https://gamebanana.com/mods/559212) | The author publishes separate Cemu and **Console Edition** ZIPs. The Console Edition archive was checked and starts with `Luigi's Lost Levels - Console Edition/content/`, one folder too deep for Coffee Shop. |
| New Super Mario Bros. U | [Mario U in the Dark](https://gamebanana.com/mods/631233) | The five-world mod has a ZIP download, but its archive root and console-specific requirements have not been verified. |
| The Wind Waker HD | [Saria in Wind Waker HD](https://gamebanana.com/mods/248073) | The author designed it as a US Cemu graphics pack and explicitly left Wii U compatibility uncertain; a console user reports a black screen. |
| Twilight Princess HD | [Canoe Dogs restoration](https://gamebanana.com/mods/454590) | The author tested it on Wii U and Cemu, but distributes the Wii U build as `.7z`. |
| Twilight Princess HD | [UI Dark Mode](https://gamebanana.com/mods/516855) | The page has Wii U SDCafiine steps, but the downloadable variants are `.7z`. |
| Xenoblade Chronicles X | [Cemu community gameplay packs](https://github.com/cemu-project/cemu_graphic_packs/blob/master/src/XenobladeChroniclesX/Mods/readme.md) | These are Cemu graphics-pack patches with version-specific presets, not Wii U SDCafiine files. |

If a creator later publishes a direct HTTPS ZIP whose root contains `content/` or `aoc/`, verify its region, dependencies, and archive contents before promoting it into a game's `game.json`. Link to the original release and credit the creator; do not repackage or mirror the mod without permission.
