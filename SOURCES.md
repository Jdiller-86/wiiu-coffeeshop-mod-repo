# Mod sources and archive checks

This ledger covers the 14 installable entries in the five `games/*/game.json` files. On **2026-10-03**, the catalog maintainer downloaded every listed ZIP, confirmed that it extracts with `content/` at the archive root, and checked its byte size and SHA-256 against the values recorded in the game JSON. The ZIPs are served by the linked hosts; this repository contains metadata only.

The creator links identify the original mod pages. The ten archives hosted by [Funtum's CoffeeShop repository](https://github.com/ItsFuntum/funtum-coffeeshop-repo) are community-hosted copies. [Funtum's README](https://github.com/ItsFuntum/funtum-coffeeshop-repo#mods) identifies the original pages and says archive layout may have been adjusted for SDCafiine. The other four downloads are served from the creator's GameBanana page or GitHub release. No archive check establishes permission to redistribute, game compatibility in every region, or successful play on hardware. This catalog does not assert a license for any mod.
