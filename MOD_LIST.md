# Mod list by game

**50 directly installable mods across eight games**, grouped below. Every entry links to its original creator page. Sizes are decimal MB (1 MB = 1,000,000 bytes). The feed contains verified ZIP metadata; physical Wii U play is not guaranteed for every mod. See [SOURCES.md](SOURCES.md) for archive links and checks, and [DISCOVERY.md](DISCOVERY.md) for major packs requiring manual setup.

Install only one large overhaul for a game at a time. Other entries can also replace the same character, course or UI file; CoffeeShop shows conflicts but does not merge files. Read each creator page before combining mods.
